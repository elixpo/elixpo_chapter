RV565, the story

Along the way, the badge needed video, so we built a format for it.

A small screen is fed through one thin wire. So smooth video isn’t about drawing faster: it’s about sending less.

Before · whole frames
Send every pixel
Even when only the bunny moved.
31.4 ms per frame · 100% of pixels
RV565 2.0 · changed rows
Send the rows that changed
Whole bands of rows, wherever something moved.
27.5 ms per frame · 87% of pixels
RV565 3.0 · changed regions
Send only what changed
Each frame records the rectangle that changed.
16.0 ms per frame · 42% of pixels

Film on the Falera Badge (ESP32-S3, 40 MHz SPI); a UI animation drops from 31.4 to 6.3 ms. At 24 FPS a frame gets 41.7 ms, and every frame arrived on time. Frame: Big Buck Bunny © Blender Foundation, CC BY 3.0.
