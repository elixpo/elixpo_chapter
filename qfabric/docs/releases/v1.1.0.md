# QFabric v1.1.0 — Matched-Load Evaluation and Correction

QFabric v1.1.0 adds the Stage 12 evaluation and the manuscript prepared for
arXiv (cs.AR). It also corrects the headline result of v1.0.x.

## Correction

The v1.0.x manuscript reported that recovery cut flagship p95 by 36.6%. That
result does not hold. The Linux path spawned a new process per invocation, so
Linux latency measured process creation (8.05 ms p95 for an addition, against
0.075 ms with a persistent executor), and the replay drew MCU latencies from
idle traces while Linux traces were loaded. Stage 12 removes both defects.

## Results

- Every MCU call costs about 19 ms of dispatch regardless of compute; the MCU
  runs the heaviest kernel 34x slower than the Cortex-A53.
- Linux contention slows the MCU path more than the Linux path, because every
  MCU call is issued and relayed by Linux processes.
- Linux meets every contract across 30 chain cells, and the controller makes
  no switches. Without hysteresis it would switch in 7 cells, raising p95 by up
  to 177x; probation rolls back 5 of those moves.
